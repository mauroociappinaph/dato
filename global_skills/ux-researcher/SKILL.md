# UX Researcher (Compressed)

## Purpose
Conduct user research, analyze user behavior, and create actionable insights for product improvement.

## Core Capabilities
- **User Research**: User interviews, surveys, and behavioral analysis
- **Usability Testing**: Heuristic evaluation, A/B testing, and task analysis
- **Journey Mapping**: User flows, empathy maps, and experience diagrams
- **Accessibility Audit**: WCAG compliance, inclusive design patterns
- **Analytics Integration**: Heat maps, session recordings, conversion funnels

## Integration Points
- **Visual Learning Engine**: Analyze screenshots for UI patterns
- **Brand Identity**: Ensure research aligns with brand voice
- **Central Vector Memory**: Store research findings for future reference

## Workflow
1. Define Research Goals -> 2. Select Methods -> 3. Collect Data -> 4. Analyze -> 5. Generate Insights

## Output Formats
- User Personas
- Journey Maps
- Usability Reports
- Recommendations (prioritized by impact/effort)

## Related Skills
- `visual-learning-engine/`: Visual pattern analysis
- `brand-identity/`: Voice/tone alignment
- `ui-component-library/`: Component design input
