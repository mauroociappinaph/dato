# Brand Identity (Compressed)

## Purpose
Provide a Single Source of Truth for design tokens, voice, and tone. Ensures cross-project consistency.

## Capabilities
- **Adaptive Identity**: MANDATORILY retrieve the "voice" and "style" of the project from **Central Vector Memory (dude-central-brain)**.
- **Visual Standards**: Consult `design-tokens.json` for UI components.
- **Communication**: Apply `voice-tone.md` guidelines to all user-facing text.

## Rules
1. **Bootstrap**: Consult this skill at the start of any new UI project.
2. **Override**: Project-specific styles in `resources/` override global defaults but must remain compatible.
