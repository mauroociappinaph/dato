# Context Manager (Compressed)

## Purpose
Supply agents with the minimum necessary, maximum relevance context using **Central Vector Memory (dude-central-brain)**.

## Capabilities
- **Pruning**: Remove noisy logs/boilerplate to maximize reasoning window.
- **Sync**: Maintain state consistency across multi-agent workflows.
- **Hybrid Search**: Combine vector similarity with keyword retrieval.

## Protocols
1. **Analyze**: Identify optimal context strategy.
2. **Retrieve**: Pull episodic/semantic nodes from Pinecone.
3. **Inject**: Place critical facts in high-attention positions.
