# Google Slides Creator (Compressed)

## Purpose
Transform raw data into professional, minimalist Google Slides decks using Exa/API.

## Design Standards (2026)
- **Aesthetic**: Dark Glassmorphism, Rule of Thirds, immersive full-bleed imagery.
- **Storytelling**: One clear data point or emotion per slide.
- **Hierarchy**: Minimal text, bold typography, limited color palette.

## Workflow
1. Analyze Topic/Mood -> 2. Generate 3-5 Key Pillars -> 3. Map to layouts -> 4. Execute via `create_deck.py`.

## Tools
- `google-api-python-client`, `dude-bridge`.
