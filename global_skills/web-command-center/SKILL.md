# Web Command Center

## Role
The "Visual HQ" that moves the agent interaction from the terminal to a beautiful, immersive web dashboard.

## Design Standards (2026 Trends)
1. **Dark Glassmorphism:** Semi-transparent cards with `backdrop-blur` and subtle borders.
2. **Neon Accents:** Using Cyan and Neon Pink for high-priority status indicators.
3. **Fluid Layout:** Responsive design that works on desktop and tablets.
4. **Animated States:** Using Framer Motion for smooth transitions between departments.

## How to use
1. **Generation:** Run `scripts/generate_ui.py`.
2. **Central Brain Visualization (2026):** Ensure the UI includes a component to query and visualize the **Central Vector Memory (dude-central-brain)**, showing the latest learned patterns and system "memory nodes".
3. **Open:** Open in browser.
4. **Interact:** Visualize Pipeline and command specialists.

## Tools
- **CSS:** Tailwind CSS (JIT via CDN).
- **Animations:** Framer Motion / Animate.css.
- **Icons:** Lucide-React / FontAwesome.
